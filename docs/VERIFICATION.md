# Проверка — Winter Edition 2026 (15 ноября 2026)

## Что сделано

**Тема и переключение**
- `js/theme.js` (синхронно в `<head>`, без вспышки): выбор посетителя (localStorage) → публичная тема владельца → Winter.
- Переключатель Winter / Classic в шапке. Classic не изменён: все зимние правила в `css/winter.css` под `html[data-theme=winter]`, элементы одной темы помечены `data-theme-only`.
- `/admin` → Settings: «Активная тема публичного сайта» (PostgreSQL, колонка `configuration.public_theme`, миграция `0002_public_theme`) и «Тема этой панели» (только браузер).
- `js/runtime.js`: статическая заглушка `{api:false}`. FastAPI отдаёт вместо неё `{api:true, theme:<из БД>}`.

**Без API — без запросов (исправлен 404)**
- Главная, подстраницы и форма не обращаются к API, если `SITE_RUNTIME.api` = false. Форма валидирует поля и честно сообщает о недоступности.

**Визуал**
- Палитра Snow / Ice / Frost / Deep Winter / Burgundy / Silver. Винные акценты и Unbounded сохранены.
- Снег на Canvas: 3 слоя глубины, дрейф, отталкивание от курсора, плавное появление за ~2 с, параллакс от прокрутки без скачков. До 140 частиц на десктопе, до 42 на мобильных и слабых устройствах. Пауза, когда вкладка скрыта или анимации остановлены. Холст под контентом (`z-index:-1`, `pointer-events:none`).
- Hero: зимнее изображение, морозное свечение, ледяные линии с прорисовкой, глубина при движении мыши (CSS `translate` от уже существующих `--mx/--my`).
- AI-схема: стеклянные узлы, ледяные линии, светящиеся сигналы, морозная пульсация, снежинки вокруг схемы (только когда схема видна). Пульт агентов и переключатели работают как раньше.
- Новые секции (только в Winter): **Frost Network** (Canvas, выбор узла мышью или кнопками легенды, озвучивание связей для скринридера), **Winter Showcase** (портфолио: на десктопе закреплённая горизонтальная прокрутка с раскрытием и параллаксом, на тач и при reduced-motion — нативный свайп со snap), **Ice Glass Cards** (матовое стекло, граница светится за курсором), **Snow Transition** (дымка между секциями), **Frozen Data** (факты о студии + демо-графики, появление из морозного размытия, отсчёт чисел).
- Админка: стеклянные панели, ледяные границы, ❄ в логотипе и разделе AI Agents, переходы между разделами, анимированные графики. Снега над таблицами и формами нет.

**Попутные исправления**
- `premium.js`: после появления секции очищается инлайн-`transform`, иначе ломалось закрепление (pin) внутри секции.
- Админка показывала «PostgreSQL» всегда. Теперь берёт тип БД из `/health` («SQLite · test mode» в тестовом режиме).
- Подстраницы: подключены тема, снег, `runtime.js` (без него они не обращались бы к API даже с backend) и favicon (был 404).

## Чем проверено и чем нет

- Админка и API проверены на **настоящем приложении FastAPI в тестовом режиме (SQLite)** с одноразовым владельцем и тестовыми заявками во временной папке. **Это не проверка production**: PostgreSQL и Docker на машине не установлены. Миграция `0002_public_theme` на PostgreSQL не запускалась.
- Порт **8000 на этой машине зарезервирован Windows** (диапазон 7944–8043), поэтому `docker compose` с портом 8000 может не запуститься; для проверки использовался 8611.
- Плавность анимаций на глаз не оценивалась: панель браузера была скрыта и не отрисовывала кадры. Конечные состояния, логика и тайминги проверены программно; горизонтальная витрина — прогоном тикера GSAP.
- Зимние изображения — собственная процедурная графика (`assets/gen-winter.py`), а не фотографии. Настоящие лицензированные фото не скачивались.
