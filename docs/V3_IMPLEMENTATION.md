# AI EMPIRE V3 — аудит и реализация

## Исходники

15 ноября 2026: обнаружен `index.html`, но не `index(1).html`. Основа — существующие HTML/CSS/JS. Git-репозитория не было; резервная копия оригиналов (`.baseline/`) перед публикацией удалена.

Сохраняем Unbounded, paper `#f6f2ef`, ink `#241c1c`, wine `#8a1f2d`, тонкие линии, split-заголовки, UA/RU/EN, раскрытие услуг, карусель с клавиатурой и drag, форму, магнитные кнопки и reduced-motion.

Backend отсутствует; контакты и бренд — заглушки; цены UAH; изображения не подключены; продукты Coming Soon; портфолио состоит из демо. Подтверждённых клиентских кейсов нет.

## Изменения по фазам

1. Расширить дизайн-систему: асимметрия, редакционная типографика, кремовые поверхности, доступный фокус, компоненты вкладок/панели/демонстраций.
2. Главная: фотографический hero, последовательные слова, SVG-конвейер с сигналами и управлением, фотографии услуг/портфолио, SaaS-вкладки, сценарная демоверсия администратора, визуальная секция. GSAP/ScrollTrigger локально; сбой анимации не блокирует контент.
3. Страницы пяти услуг, трёх продуктов, портфолио. Демонстрации явно обозначены; нет вымышленных клиентов, результатов и отзывов.
4. FastAPI + PostgreSQL, миграции, серверная валидация, антиспам, авторизация владельца, CRM и аудит. Статические файлы обслуживаются по разрешённому списку.
5. `/admin`: Overview, CRM, Leads, Projects, AI Agents, Finance, Analytics, Content Manager, Pricing Manager, Settings. Реальные API-данные, пустые состояния вместо фиктивных финансов.
6. Серверные адаптеры Claude/Codex, журнал задач, лимиты, остановка. Внешние вызовы требуют настройки владельцем; ключей в браузере нет.
7. Проверки API, прав, CSRF, антиспама, CRUD, responsive/reduced-motion, SEO и ресурсов. Фактические результаты — в `docs/VERIFICATION.md`.

## Дизайн-система

Основа `css/style.css`, расширение `css/premium.css`. Контент до 1440px, поля 5vw, секции 96–140px, мобильные поля 20px. Unbounded для заголовков и подписей, системный sans-serif для длинного текста. Wine — для действий и сигналов; статусы имеют текстовые подписи. GSAP — hero/маски/сборка SVG, CSS — hover/вкладки, Canvas — лёгкие существующие частицы. Без 3D и перехвата прокрутки. При reduced-motion отключены параллакс, бесконечные сигналы и длительные переходы.

## Запуск

Команды — в `README.md` и `backend/README.md`. PostgreSQL обязателен для рабочего режима; SQLite — только для изолированных тестов. Проект для локального запуска/сервера владельца на FastAPI/PostgreSQL; публикация в Sites не выполняется.
