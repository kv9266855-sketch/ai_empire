# AI EMPIRE — Control room

Админка доступна по `/admin` через FastAPI. Отдельная сборка не требуется: vanilla JavaScript, CSS и HTML.

- Авторизация: `POST /api/v1/auth/login`; сессия в HttpOnly cookie; CSRF-токен загружается из `/auth/me` и добавляется к изменениям.
- Рабочие разделы: Overview, CRM, Leads, Projects, AI Agents, Finance, Analytics, Content Manager, Pricing Manager, Settings.
- Записи, показатели, журналы и графики берутся из API. Демо-метрики не используются.
- Content Manager поддерживает тексты UA/RU/EN, услуги, SaaS-продукты, портфолио и загрузку фотографий. Портфолио по умолчанию помечается как демонстрационное.
- Pricing Manager редактирует отдельные USD-тарифы для сайтов, AI-ботов, автоматизаций и SaaS; месячные и разовые платежи.
- Задачи AI запускаются только по действию владельца и с явным резервом расходов. Есть пауза агента, отмена задачи, просмотр логов и аварийная остановка всех задач.
- Пароли и ключи провайдеров в браузере не сохраняются. Сессия не хранится в localStorage.
- Поля API выводятся через `textContent`/DOM; динамический HTML не интерполируется. Диалоги поддерживают Escape, клавиатуру и возврат фокуса. Анимации отключаются при `prefers-reduced-motion`.

## Проверка

```powershell
node --check admin/admin.js
```

После запуска backend и создания владельца откройте `/admin`: войдите, создайте/измените запись, проверьте её через обновление страницы; измените тариф и проверьте публичную страницу. Авторизованные запросы требуют работающей PostgreSQL и созданного владельца (см. backend/README.md).

Пагинация: 50 записей в таблицах; CRM показывает последние 200 заявок с явным уведомлением, если в базе их больше. Поиск фильтрует текущую загруженную страницу. Изменения публичного контента отражаются после обновления сайта.
